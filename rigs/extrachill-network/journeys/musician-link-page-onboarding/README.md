# musician-link-page-onboarding

A non-technical musician discovers Extra Chill, signs up, and sets up their
Link Page: adds a link, changes the colors, and turns on the newsletter
signup with a custom message. Then a fan subscribes. The journey also maps
every place in the network that should lead the musician back to the Link
Page editor.

No persona is pinned. The Gardner contract (`personas/gardner.v1.json`) is a
network team member with elevated capabilities, which is the opposite of a
first-time musician. The musician here is a single-scenario fixture user
(`porch_lights_fixture`, ID 601), created in `seed.php`, per
`personas/README.md`.

## What it walks

| Step | Door / surface | Why |
| --- | --- | --- |
| `discover-power-from-link-page-footer` | `extrachill.link/` → `extrachill.com/power/` → Artist Platform card | Every Link Page footer says "Powered by Extra Chill" and links to `/power/`. |
| `power-page-mobile` | `/power/` at 390px | Most Link Page traffic is mobile. |
| `join-link-live-signup` | `extrachill.link/join` → join modal → register → onboarding → create artist → Create Link Page CTA → editor | The explicit signup door. |
| `join-link-mobile` | `/join` at 390px | |
| `musician-creates-artist-profile` | `/create-artist/` as the fixture musician | Creating the artist leaves no Link Page; the musician clicks Create Link Page on `/manage-link-page/`, then lands in the editor. |
| `musician-navigation-map` | artist home, `/manage-artist/`, `/manage-link-page/`, `/analytics/`, community home, main home | Every link that should lead to the editor, and where it actually goes. |
| `musician-edits-link-page` | `extrachill.link/edit` | Add a Bandcamp link, set colors (Customize), set the inline subscribe form and a custom description (Advanced), save, view the public page, reload the editor. |
| `fan-subscribes-inline` | public Link Page at 390px | A fan uses the inline form the musician enabled. |
| `musician-editor-mobile` | `extrachill.link/edit` at 390px | |
| `logged-out-editor-entry` | `extrachill.link/edit` with no session | A bookmark or an old link. |

`grade.php` checks what actually persisted: the join account and its
onboarding flags, the artist profile, no owned Link Page immediately before the CTA POST and exactly one published
page afterward (case `link-page-created-only-after-cta`), the saved colors, subscribe settings, and links, and
the fan's subscriber row.

## Regression contract

This journey runs nightly and on rig PRs (`.github/workflows/journeys.yml`).
Every known finding is pinned in `grade.php`'s `$known_findings` to the issue
that owns it. The grade throws, and the boot fails, when:

- a case produces a finding that isn't pinned (a new regression), or
- a pinned case passes (the fix landed, so remove the pin and let the case
  guard it from now on).

Skips never fail. They mean an earlier case couldn't set things up.

## Sandbox substitutes (`sandbox-fixture.php`)

Each one stands in for missing infrastructure. None of them changes product
behavior.

- **Turnstile bypass and no mail.** Uses the product's own
  `extrachill_bypass_turnstile_verification` seam, same as `auth-multisite`.
- **Rig-level substitutes** (http URL resolution, the redirect-host re-merge,
  SQLite advisory locks, the Redis-less rate-limiter stores) now live in the rig's generated
  `ec-network-sandbox-compat.php` (extrachill-network#302), not here.
- **Observation sink** (`?musician_journey_observe=1`).
  `wordpress.browser-actions` only keeps an `evaluate` value when the step
  asserts. This journey is exploratory, so each observation POSTs itself and
  `grade.php` prints the list. `evidence/observation-labels.json` maps labels
  to expressions.
- **Fatal recorder.** Stores `error_get_last()` on shutdown so a blank page
  carries its cause.

## Regenerating `journey.json`

`journey.json` has long `steps-json` strings, so it is generated by
`build-journey.mjs`. Edit the steps there, then:

```bash
node build-journey.mjs            # rewrites journey.json + evidence/observation-labels.json
node ../../tests/contract.test.mjs
```

## Running

```bash
HOMEBOY_SETTINGS_JSON='{
  "extrachill_theme_source": "/path/to/extrachill-theme-checkout",
  "extrachill_journeys": ["musician-link-page-onboarding"]
}' homeboy rig up extrachill-network
```

A full boot plus this journey takes about 15 minutes.
