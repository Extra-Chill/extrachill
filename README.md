# Extra Chill

The Extra Chill WordPress network ([extrachill.com](https://extrachill.com) and its 10 sibling sites) in one repository: the theme, every `extrachill-*` plugin, and the shared npm packages.

See [MONOREPO.md](MONOREPO.md) for the layout, what deploys to which site, and the CI/deploy model. Start at the [documentation map](docs/README.md) for documentation conventions, component references and the architecture overview.
