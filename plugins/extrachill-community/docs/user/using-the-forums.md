# Using the Forums

Forums make it easy to find people talking about music you care about. Browse a forum to read topics, start a discussion, or reply to a member.

## Start a topic

1. Open the forum that matches your subject, such as Music Discussion or Local Scenes.
2. Choose the new topic option.
3. Add a clear title and write your post in the editor.
4. Add an image if it helps explain or illustrate your post.
5. Submit your topic.

## Reply to a topic

Open the discussion and use its reply box to add your response. You can include an image and use @ followed by a member's name to mention them. They may receive a notification about the mention.

You can upvote topics and replies that you find useful or enjoyable. If an option is missing, sign in and check that you are in a forum where you can post.
